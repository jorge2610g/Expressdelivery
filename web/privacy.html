Política de privacidad

Última actualización: 1 de octubre de 2026.

Esta Política explica cómo la aplicación Express accede, recopila, utiliza, protege y elimina datos cuando una persona usa las funciones de pasajero, conductor, seguridad, soporte, pagos o billetera.

1. Datos que tratamos

  • Cuenta: nombre, correo electrónico, teléfono, identificador de usuario, preferencias de cuenta y, si se proporciona, imagen de perfil.
  • Ubicación: ubicación aproximada o precisa necesaria para mostrar el mapa, determinar origen/destino, localizar conductores, prestar un viaje y funciones de seguridad. Cuando un conductor está en línea o existe un viaje activo, Express puede mantener la ubicación actualizada mediante un servicio visible de Android.
  • Viajes y servicios: origen, destino, coordenadas, estado, distancia, duración, tarifa, cancelaciones, ofertas, historial y calificaciones.
  • Seguridad y soporte: contactos de confianza que el usuario agregue, eventos SOS, mensajes de soporte y mensajes vinculados al servicio.
  • Pagos y billetera: importes, moneda, método, estado, comisiones y referencias de transacción. Express no necesita almacenar el número completo de una tarjeta. Si se habilita un procesador externo, sus propios términos y política también pueden aplicar.
  • Datos técnicos: tokens de notificación, suscripciones push, versión de la app, registros de errores y eventos técnicos necesarios para seguridad, diagnóstico y funcionamiento.

Publicidad

Cuando la publicidad esté habilitada en la aplicación de pasajero, Express puede mostrar anuncios mediante Google Mobile Ads. El proveedor publicitario puede procesar identificadores publicitarios, información básica del dispositivo, dirección IP y datos técnicos necesarios para entregar, medir, limitar fraude y reportar anuncios, de acuerdo con la configuración de consentimiento y las políticas aplicables. Express no usa la ubicación precisa solicitada para prestar el viaje como permiso destinado a publicidad.

2. Para qué usamos los datos

Usamos estos datos para crear y administrar cuentas, prestar viajes y entregas, conectar pasajero y conductor, calcular/mostrar rutas y tarifas, enviar notificaciones, operar funciones SOS, procesar movimientos de billetera, brindar soporte, prevenir abuso, investigar fallos y cumplir obligaciones aplicables.

3. Permisos del dispositivo

Express puede solicitar ubicación aproximada o precisa y notificaciones. Los permisos se solicitan para funciones visibles relacionadas con transporte, mapas, seguimiento del servicio y avisos. Express no usa la ubicación con el único fin de publicidad y no solicita ACCESS_BACKGROUND_LOCATION.

4. Proveedores y terceros

Para operar el servicio podemos utilizar proveedores de infraestructura, autenticación, base de datos, almacenamiento, notificaciones y mapas/rutas. Entre los servicios tecnológicos utilizados se encuentran Supabase y Google Firebase Cloud Messaging. Los datos solo se comparten en la medida necesaria para prestar esas funciones o cuando exista una obligación legal.

5. Seguridad

Aplicamos autenticación, controles de acceso, políticas a nivel de datos, conexiones cifradas y separación de credenciales servidor/cliente. Ningún sistema es infalible, por lo que también monitorizamos errores y abuso para reducir riesgos.

6. Conservación y eliminación

Mantenemos datos mientras la cuenta está activa y mientras sean necesarios para prestar el servicio. El usuario puede eliminar su cuenta desde Perfil → Privacidad y datos → Eliminar mi cuenta. La eliminación borra la cuenta de autenticación y los datos personales asociados gestionados por Express.

Determinados registros pueden conservarse de forma limitada y sin información personal directa cuando sean necesarios para seguridad, prevención de fraude, resolución de disputas, contabilidad u obligaciones legales.

7. Solicitar eliminación fuera de la app

También puedes solicitar la eliminación desde nuestra página pública de eliminación de cuenta.

8. Privacidad de menores

Express es un servicio de transporte y no está diseñado específicamente como una aplicación dirigida a niños. Si detectamos información de un menor tratada de forma incompatible con la normativa aplicable, podremos eliminarla.

9. Cambios de esta política

Podemos actualizar esta Política cuando cambien las funciones, proveedores o requisitos legales. La fecha de actualización se mostrará en esta página.

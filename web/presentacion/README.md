# Express Moto — presentación para el público

Ruta prevista: https://expressviajes.online/presentacion/

Es un simulador de demostración; no solicita viajes reales ni se conecta al backend de Express. Reproduce la identidad azul/amarilla y los pasos documentados de la aplicación Flutter, pero **no es una captura exacta píxel por píxel de Android**.

## Edición permanente en línea

1. Abre web/presentacion/contenido.json en el repositorio jorge2610g/Expressdelivery.
2. Pulsa el lápiz en GitHub, modifica título, descripción, consejos o datos de ejemplo.
3. Guarda el cambio en main, conforme a la revisión establecida del repositorio.
4. Espera que la acción Deploy Flutter Web to GitHub Pages termine correctamente. Recarga /presentacion/; la dirección no cambia.

También puede actualizarse el diseño en web/presentacion/index.html sin crear otra presentación nueva. La copia distribuida en HTML continúa funcionando sin conexión con sus valores por defecto.

**Importante:** El conductor funciona en la aplicación Android original; esta demostración usa pantallas simuladas para explicar ese recorrido sin generar operaciones en producción.
